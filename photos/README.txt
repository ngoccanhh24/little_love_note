Đặt các file ảnh album vào thư mục này (ví dụ: photo1.jpg, photo2.jpg...).
Sau đó mở config/content.json và liệt kê các file ảnh trong mảng "photos":

"photos": [
  { "src": "photo1.jpg", "caption": "một chiếc kỷ niệm ♡" },
  { "src": "photo2.jpg", "caption": "một chiếc kỷ niệm ♡" }
]

Xem hướng dẫn chi tiết tại file README.md trong thư mục gốc.
